# Student Academic Performance & Social Media Usage Analysis 📚📱

A data science project analyzing the relationship between students' academic performance and their social media engagement patterns. This project aims to understand how different aspects of social media usage impact academic achievements.

## 📊 Project Overview

This repository contains code and analysis for studying the correlation between students' academic performance and their social media usage patterns. The project uses machine learning techniques to identify key factors affecting academic outcomes.

## 🗂️ Repository Structure

```
├── model.py                        # Main machine learning model implementation
├── data.csv                        # Dataset containing student information
├── correlation_heatmap.png         # Visualization of feature correlations
├── feature_importance.png          # Feature importance analysis
├── time_spent_vs_performance.png   # Time spent vs academic performance analysis
└── Screenshot 2024-09-13 160058.png # Additional visualization
```

## 📈 Dataset Features

The dataset (`data.csv`) includes various metrics about students:

- Social media usage patterns
- Time spent on different platforms
- Engagement metrics
- Academic performance indicators
- Demographic information

## 🛠️ Technical Implementation

### Prerequisites

```python
- Python 3.8+
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
```

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kanizmadix/student-academic-performance-based-on-social-media-usage-and-engagemements.git
cd student-academic-performance-based-on-social-media-usage-and-engagemements
```

2. Install required packages:
```bash
pip install -r requirements.txt
```
